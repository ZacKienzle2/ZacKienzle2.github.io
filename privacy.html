Privacy policy

This policy covers the rclone backup client, a Google OAuth client used only by its owner.

Data accessed

The client requests the Google Drive drive.file scope. It can read and change only the files and folders it creates in the owner's Drive, which are backups of a market data recording. It cannot see any other file.

Use and storage

The files are used only to restore and analyse that recording. The OAuth token is stored only in rclone's configuration on the owner's server.

Sharing

No data is sold, shared with or disclosed to any third party.

Revoking access

Access can be revoked at any time from the Google Account's third-party connections page, which also removes the client's authorization.
